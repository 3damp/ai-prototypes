# Moth Night

A breeding game prototype: pair moths, breed for traits, and fill collectors' orders for specific wing patterns and colours.

- **Play:** [index.html](index.html), or the GitHub Pages link in the root README
- **Format:** a single self-contained HTML file, no build step
- **Save data:** stored in the player's own browser (`localStorage`)
- **Languages:** English, Spanish
- **Testing panel:** a hidden panel for tuning genes and scoring opens with a keyboard shortcut or 5 taps
