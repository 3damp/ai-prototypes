# Paint Mixer

A colour mixing toy: drag paint into a dish and keep adding to mix. Colours blend like real pigment, so blue and yellow make green.

- **Play:** [index.html](index.html), or the GitHub Pages link in the root README
- **Format:** a single HTML file, no build step
- **Mixing:** uses [Mixbox](https://github.com/scrtwpns/mixbox), loaded from a CDN
